How to read this
  • Goal code: 8 blocks (rows) × 8 classes. Click or drag a row to set it; hover to preview.
  • Image: what the world model decodes the goal into (code → goal decoder → WM state → image decoder).
  • World-model goal: the decoded 1024-dim hidden state, in order; each of its 8 blocks is a band of 4 rows. Blue below 0, red above.
  • Mask (mask arm only): the whole code decides which WM blocks the goal keeps ✓ or ignores ✕ (faded). Code row b and WM block b are unrelated. The image uses the unmasked goal.
  • Jump: the ε-greedy distant jump (large class-index distance). Move: a new code at a set distance, in class steps or in goal space.
  • Save: freeze a state; the panel then compares the current one to it.
  • Values are the agent's own heads at that state: manager task value, manager exploration value, worker value on its goal, reward, continue probability.
  • Each panel is the 4M checkpoint of the best of 5 seeds for that arm.
